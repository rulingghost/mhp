Vercel KV Veritabanını Bağlama (30 Saniye)

Vercel sunucusuz (serverless) mimaride diske dosya yazılmasına izin vermez. Değişikliklerin canlı sitede kalıcı kalması için ücretsiz Vercel KV veritabanını projenize bağlamanız yeterlidir:

  1. 1 Vercel Dashboard'a girip projenizi seçin ve üst menüden Storage sekmesine tıklayın.
  2. 2 Create Database butonuna basıp KV (Serverless Redis by Upstash) seçeneğini seçip oluşturun.
  3. 3 Oluşturduktan sonra Connect Project butonuna basarak projenize bağlayın.
Vercel tüm bağlantı değişkenlerini projenize otomatik tanımlar. Başka hiçbir koda dokunmanıza gerek kalmaz!
